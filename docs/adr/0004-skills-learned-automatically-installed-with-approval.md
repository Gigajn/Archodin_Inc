# Skills are found and refined automatically, but installed only with a person's approval

Archodin follows a Hermes-style learning loop: Agents write and refine Skills, owned by their Role, (`SKILL.md`, agentskills.io format) from experience, and Ronin (the scout) searches for Skills a task needs before work is assigned. Searching is automatic, free and needs no login: a self-hosted SearXNG when configured, DuckDuckGo otherwise, plus the GitHub API, where an optional GitHub login in the console raises rate limits and enables code search. Every new or changed Skill, whether downloaded or written by an Agent, is checked by Vigil (the inspector) and then held by Codex (the curator) until a person approves it in the Agora, grouped per Role; scripts inside a Skill stay disabled until approved separately. Every change is kept as a version that can be rolled back. Automatic updates are limited to Skills and memory; they never touch Provider configuration or Tool permissions, and Archodin's code changes only through pull requests a person merges (ADR 0006). A downloaded Skill is instructions and scripts from a third party that every later run will follow, so letting it in unreviewed would be the easiest way to take over an Agent.
