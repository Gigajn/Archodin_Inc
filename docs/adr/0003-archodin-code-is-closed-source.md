# Archodin's own code is closed-source for now

Code written for Archodin is proprietary (all rights reserved) and the repository stays private, while the imported langchain-rust code remains under its MIT license, whose `LICENSE` file and "Copyright (c) Ryo Kanazawa" notice must ship with any distribution that includes it. MIT allows combining it with closed code. Fixes to upstream files that we send back as PRs (ADR 0001) are published under MIT by definition, so they must not contain Archodin-only code.
