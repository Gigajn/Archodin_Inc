# Archodin and Basileia

Archodin provides a reusable foundation for agent applications. Basileia is the AI-company application built on that foundation.

## Language

**Archodin**:
The reusable library underlying Basileia and other agent applications, independent of any particular company's agents or workflows.
_Avoid_: Basileia, AAHC, company application

**Basileia**:
The AI-company application built on Archodin, including its company agents and operational workflows.
_Avoid_: AAHC, Archodin

**Agora**:
Basileia's human-facing web console for interacting with and overseeing the AI company.
_Avoid_: Basileia (when referring only to its web console)
