# .scratch/ — Arsip perencanaan (bukan sumber kebenaran)

Folder ini adalah arsip catatan/draf perencanaan yang dibawa dari workspace `master` (aahc-core) ke `main` lewat PR #33. Isinya: spec Basileia (milestone 0–6 + roadmap), spec AAHC historis + 20 tiket legacy, dan hasil spike kompatibilitas.

Yang berlaku di repo ini adalah ADR 0007 (library Archodin MIT, aplikasi Basileia proprietary). Dokumen di sini adalah baseline perencanaan yang "approved planning baseline, not implementation authorization" — bukan otorisasi implementasi.

Catatan: sebagian referensi di dokumen ini menggantung di `main` — `Goals.md`, `scripts/check.sh`, `scripts/frontier.py`, dan crate `aahc_core` tidak ada di `main` (berasal dari workspace `master`). Bukti gate (`gate-output.txt`, "14 integration tests") juga berasal dari workspace tersebut dan tidak dapat direproduksi dari `main`. Jangan mengutip dokumen ini sebagai bukti sesuatu sudah selesai di `main`.
